# Multivariate Cryptography

## Суть

Multivariate cryptography использует системы многомерных полиномиальных уравнений над конечным полем. Public map выглядит как набор квадратичных полиномов многих переменных, а private key хранит структуру и обратимые аффинные преобразования, позволяющие эффективно находить прообраз.

## Как устроено

- Central map выбирается из семейства с известным владельцу способом инверсии.
- Два аффинных преобразования скрывают входную и выходную структуру.
- Public key — раскрытая композиция в виде системы полиномов.
- Подпись обычно хэширует сообщение в целевой вектор и с trapdoor находит подходящий прообраз.
- Размеры ключей и число уравнений зависят от поля, числа переменных и структуры central map.

## Практический разбор

Анализ параметров должен учитывать не только generic решение системы, но и атаки, восстанавливающие скрытую структуру. Поэтому семейства и наборы параметров нельзя взаимозаменять по одному размеру ключа.

## Ограничения и безопасность

- Специальная структура, необходимая для trapdoor, может дать более быстрый криптоанализ.
- Ошибки и неоднозначность при инверсии должны обрабатываться без oracle.
- Конкретные схемы и их статус из курса требуют отдельной актуализации перед применением.
