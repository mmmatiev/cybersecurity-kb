# Algebraic Structures

## Суть

Алгебраическая структура — множество с одной или несколькими операциями и заданными законами. Полугруппы, моноиды, группы, кольца и поля образуют последовательность всё более сильных требований; криптографические алгоритмы используют эти требования, чтобы операции были корректны и обратимы там, где это необходимо.

## Как устроено

- Операция должна быть всюду определена, однозначна и замкнута на множестве.
- Ассоциативность позволяет не фиксировать расстановку скобок; нейтральный элемент не меняет операнд; обратимый элемент возвращает нейтральный.
- Группа требует ассоциативности, нейтрального и обратного для каждого элемента; абелева группа дополнительно коммутативна.
- В циклической группе каждый элемент является степенью одного образующего; порядок элемента делит порядок конечной группы.

## Ключевая формула

Для циклической группы порядка $n$ порядок степени образующего вычисляется как $$\operatorname{ord}(g^k)=\frac{n}{\gcd(n,k)}.$$

<!-- reviewed-notation:start -->
**Обозначения и условия.** g — образующий конечной циклической группы, n≥1 — число её элементов; k — целое, ord — наименьшая положительная степень, дающая единицу. НОД берётся для n и |k|; при k=0 результат равен 1. Это порядок элемента, не его числовое значение.
<!-- reviewed-notation:end -->

## Практический разбор

<!-- reviewed-example:start -->
*Происхождение:* Семинар 01, стр. 1–3; подробная подстановка в пример курса.

**Исходные данные.** Операция a*b=3a−2b на вещественных числах; x=1,y=2,z=−1.

1. y*z=6+2=8, затем x*8=3−16=−13.
2. x*y=3−4=−1, затем (−1)*z=−3+2=−1.

**Результат.** Две расстановки скобок дали −13 и −1: ассоциативности нет.

**Проверка.** Подстановка в раскрытые выражения 3x−6y+4z и 9x−6y−2z даёт те же значения.

**Граница применимости.** Один контрпример достаточен для опровержения ассоциативности; несколько совпадений не доказывают её для всех вещественных чисел.
<!-- reviewed-example:end -->

### Дополнительное пояснение из конспекта

### Семинар 01 — проверка структуры

Для операции $a*b=3a-2b$ на $\mathbb R$ сначала подтверждаются всюду определённость, однозначность и замкнутость. Затем раскрываются обе расстановки скобок:

$$x*(y*z)=3x-6y+4z,\qquad (x*y)*z=9x-6y-2z.$$

При $x=1$, $y=2$, $z=-1$ получаются $-13$ и $-1$, поэтому операция неассоциативна. Двустороннего нейтрального элемента нет, коммутативность опровергается парой $x=3$, $y=5$, но оба уравнения $a*x=b$ и $y*a=b$ разрешимы однозначно. Итог: это квазигруппа, но не группа.

### Семинар 02 — циклическая группа порядка 18

Для $G=\langle x\rangle$, $|G|=18$, порядок $x^k$ находится по формуле выше. Образующие — $x,x^5,x^7,x^{11},x^{13},x^{17}$, потому что соответствующие показатели взаимно просты с 18. Остальные элементы порождают подгруппы порядков 9, 6, 3 и 2; это позволяет восстановить структуру подгрупп без перебора всех степеней.

## Ограничения и безопасность

- Название операции не гарантирует групповых свойств — каждое условие проверяется отдельно.
- Абстрактная группа описывает законы операций, но конкретная криптографическая стойкость зависит от выбранной группы и сложности обратной задачи.
