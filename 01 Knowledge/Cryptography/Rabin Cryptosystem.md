# Rabin Cryptosystem

## Суть

Rabin шифрует сообщением-квадратом `c=m² mod n` для `n=pq`. Расшифрование требует знания p и q, извлекает корни по каждому простому модулю и объединяет их CRT. Вычислительная инверсия тесно связана с факторизацией, но результат даёт четыре кандидата.

## Как устроено

- Public key — n, private key — его простые множители.
- Шифрование выполняет одно модульное возведение в квадрат.
- По p и q получают пары корней `±r` и `±s`.
- Четыре комбинации знаков через CRT дают четыре корня по n; encoding должен однозначно выбрать исходное сообщение.

## Ключевая формула

Шифрование использует $$c=m^2\pmod n,\qquad n=pq.$$ При известном разложении сначала находят корни по $p$ и $q$, затем объединяют их по CRT в четыре кандидата.

<!-- reviewed-notation:start -->
**Обозначения и условия.** p,q — различные нечётные простые, n=pq; m — представитель 0…n−1, c — квадрат mod n. Ровно четыре различных корня возникают для m, взаимно простого с n; при кратности одному фактору число корней меньше. Выбор правильного сообщения из корней требует отдельного кодирования.
<!-- reviewed-notation:end -->

## Практический разбор

<!-- reviewed-example:start -->
*Происхождение:* Составленный учебный пример; не экспериментальный результат курса.

**Исходные данные.** n=77=7·11, m=20; шифрование c=m² mod n.

1. 20² mod 77=400 mod 77=15.
2. Корни 15 mod 7=1: 1 и 6; mod 11=4: 2 и 9. Перебор допустимых классов подтверждает корни 13,20,57,64.

**Результат.** Четыре кандидата сообщения соответствуют одному c=15.

**Проверка.** 13²=169≡15,20²≡15,57²≡15,64²≡15 mod 77.

**Граница применимости.** Само извлечение квадратного корня не выбирает исходное 20. Протокол должен однозначно кодировать сообщение и учитывать активные атаки.
<!-- reviewed-example:end -->

### Дополнительное пояснение из конспекта

Семинар 11 разбирает математическое ядро расшифрования на $n=1457=31\cdot47$. Корни из 811 равны $\pm6$ по модулю 31 и $\pm24$ по модулю 47. Из коэффициентов Безу $c=-3$, $d=2$ строятся

$$x=(6\cdot2\cdot47+24\cdot(-3)\cdot31)\bmod1457=1246,$$

$$y=(6\cdot2\cdot47-24\cdot(-3)\cdot31)\bmod1457=1339.$$

Полный ответ — классы $\pm1246$ и $\pm1339$. Само уравнение не указывает, какой из четырёх корней был исходным сообщением; способ разрешения этой неоднозначности должен определяться схемой применения.

## Ограничения и безопасность

- Textbook Rabin не задаёт безопасное кодирование и аутентификацию.
- Неоднозначность расшифрования — часть конструкции, а не ошибка реализации.
- Публикация информации, позволяющей различать корни не по формату, может создать oracle.
