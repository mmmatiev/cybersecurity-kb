# Modular Exponentiation

## Суть

Модульное возведение в степень вычисляет `a^e mod n` без построения огромного промежуточного числа. Двоичный алгоритм square-and-multiply раскладывает показатель по битам и после каждого умножения выполняет редукцию по модулю.

## Как устроено

- Начальное значение аккумулятора равно 1, основание предварительно приводится по модулю n.
- На каждом бите основание возводится в квадрат; при установленном бите аккумулятор дополнительно умножается на текущее основание.
- Число шагов пропорционально длине двоичной записи e.
- Для группового элемента показатель можно дополнительно сокращать по известному порядку группы.

## Практический разбор

Для проверки ручного расчёта полезно выписать двоичный показатель и таблицу квадратов `a^(2^i) mod n`, затем перемножить только выбранные строки. Такой же шаблон используется в RSA, Diffie–Hellman и ElGamal.

## Ограничения и безопасность

- Время исполнения наивной реализации зависит от битов секретного показателя и создаёт timing side channel.
- Редукция показателя допустима только при выполнении условий соответствующей теоремы или знании порядка элемента.
