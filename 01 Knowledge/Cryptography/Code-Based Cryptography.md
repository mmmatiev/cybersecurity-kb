# Code-Based Cryptography

## Суть

Code-based cryptography использует трудность декодирования случайного линейного кода с ошибками. Trapdoor состоит в знании структурированного кода и преобразований, скрывающих его; публичная задача выглядит как декодирование без эффективного алгоритма.

## Как устроено

- McEliece публикует замаскированную generator matrix; сообщение кодируется и к codeword добавляется ограниченный вектор ошибок.
- Владелец secret structure снимает маскировку и декодирует исправляемое число ошибок.
- Niederreiter использует parity-check/syndrome formulation той же основной трудности.
- Security parameters включают длину кода, размерность и допустимый вес ошибки.
- Ключи обычно значительно крупнее, чем у RSA/ECC и ряда lattice schemes.

## Практический разбор

Разбор схемы должен отдельно проверять кодирование сообщения, распределение ошибки и защиту декодера. Некорректное сообщение об ошибке или время декодирования может превратить private decoder в oracle.

## Ограничения и безопасность

- Структурные свойства выбранного семейства кодов не должны облегчать восстановление trapdoor.
- Большой public key влияет на provisioning и формат сертификатов.
- CCA security требует преобразования базовой one-way конструкции, а не следует автоматически из декодирования.
