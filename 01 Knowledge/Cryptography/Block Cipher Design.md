# Block Cipher Design

## Суть

Блочный шифр по ключу задаёт обратимую подстановку на блоках фиксированной длины. Практические конструкции собирают сложное преобразование из раундов: нелинейных замен, линейного рассеивания, перестановок и добавления раундового ключа.

## Как устроено

- Confusion скрывает связь ключа и шифротекста, diffusion распределяет влияние одного входного бита по состоянию.
- Feistel network остаётся обратимой даже при необратимой раундовой функции, если половины меняются по заданному правилу.
- Substitution–permutation network применяет обратимые S-box и линейные слои ко всему состоянию.
- Key schedule получает раундовые ключи; его структура должна избегать простых связей между ними.

## Практический разбор

Avalanche effect проверяется изменением одного бита входа или ключа: после достаточного числа раундов меняется примерно половина выходных битов. Это полезная диагностика, но не самостоятельное доказательство стойкости.

## Ограничения и безопасность

- Размер блока ограничивает безопасный объём данных под одним ключом из-за birthday bound.
- Число раундов выбирают с запасом относительно лучших известных дифференциальных, линейных и структурных атак.
