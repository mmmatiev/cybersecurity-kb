# Digital Image File Formats

## Суть

Формат изображения определяет, как упакованы пиксели или графические объекты, metadata, палитра и сжатые данные. Расширение файла не гарантирует способ хранения: для анализа нужно учитывать фактический контейнер и кодек.

## Как устроено

- BMP в курсе служит примером непосредственного растрового хранения без обязательного сжатия.
- GIF использует палитру и поддерживает последовательность кадров.
- PNG сочетает предиктивные фильтры с алгоритмами без потерь; JPEG хранит результат преобразования и квантования с потерями.

## Пример из курса

Слайды сопоставляют BMP, GIF, PNG и другие форматы по представлению цвета, сжатию и поддерживаемым возможностям.

## Ограничения и безопасность

- Metadata и дополнительные секции могут переживать или не переживать пересохранение независимо от пикселей.
- Для стеганографии существенна вся цепочка декодирование–редактирование–повторное кодирование, а не только исходное расширение.
