# Linear Cryptanalysis

## Суть

Linear cryptanalysis ищет линейные приближения между битами plaintext, ciphertext и key, которые выполняются с вероятностью, отличной от 1/2. Небольшое смещение накапливается на множестве известных пар и позволяет статистически ранжировать кандидаты раундового ключа.

## Как устроено

- Для S-box строят linear approximation table и находят маски с ненулевым bias.
- Приближения раундов объединяют; piling-up показывает, как перемножаются смещения независимых выражений.
- По known plaintext/ciphertext вычисляется статистика для кандидатов части последнего ключа.
- Наиболее отклоняющийся счётчик указывает вероятный кандидат, после чего оставшиеся биты проверяются отдельно.
- Data complexity растёт примерно обратно квадрату общего bias.

## Ключевая формула

Линейная аппроксимация полезна, когда её вероятность $$P=\tfrac12+\varepsilon$$ имеет ненулевое смещение $\varepsilon$; накопление статистики позволяет отличать её от случайного соотношения.

## Практический разбор

Атака оценивает design margin блочного шифра. Увеличение числа раундов уменьшает полезное смещение, а S-box проектируют так, чтобы максимальные линейные корреляции были малы.

## Ограничения и безопасность

- Предположение независимости приближений может завышать или занижать оценку.
- Теоретическое преимущество над brute force не обязательно делает атаку практичной.
- Side-channel leakage может давать более сильный сигнал, чем математическое линейное приближение.
