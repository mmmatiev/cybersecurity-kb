                                 Разбор заданий: материал 10

                                Вычисление символа Лежандра



     Данный материал демонстрирует разбор задания, посвященного проверке
разрешимости квадратичных сравнений с одним неизвестным с использованием свойств
символа Лежандра.
                                     𝑎
     Символ    Лежандра          (𝑝)      —   это   функция,   указывающая     на    то,   является
𝑎 ∈ {1, 2, … , 𝑝 − 1} квадратичным вычетом или невычетом по модулю 𝑝 > 2:
       𝑎
     - (𝑝) = +1, если 𝑎 — квадратичный вычет по модулю 𝑝;
       𝑎
     - (𝑝) = −1, если 𝑎 — квадратичный невычет по модулю 𝑝.
     Число 𝑎 называется квадратичным вычетом по модулю 𝑝, если квадратичное
сравнение 𝑥 2 ≡ 𝑎 (mod 𝑝), 𝑝 > 2, 𝑎 ∈ {1, 2, … , 𝑝 − 1} разрешимо (имеет два решения).
     Число 𝑎 называется квадратичным невычетом по модулю 𝑝, если данное сравнение не
имеет решений.
     Для нахождения символа Лежандра может быть использован критерий Эйлера,
критерий Гаусса или же квадратичный закон взаимности совместно со свойствами символа
Лежандра.
     Пример.
                                              561
     Вычислить символ Лежандра (757) с помощью его свойств и с использованием
квадратичного закона взаимости.
     Решение.
     Разложим число 561 на простые множители, что для малых чисел является достаточно
простой задачей, и получим 561 = 3 ∙ 11 ∙ 17. Следовательно, данный символ Лежандра
можно представить в виде произведения трех символов Лежандра:
      561      3       11       17
     (757) = (757) (757) (757).
     Последовательно найдем значения отдельных символов Лежандра, входящих в
полученнное произведение.
                                     3
     1) Символ Лежандра (757).
     К данному символу Лежандра нельзя применить какое-либо свойство из основного
перечня. Поэтому преобразуем его с использованием квадратичного закона взаимности.
Для этого необходимо привести значения, образующие данный символ Лежандра, по
                                                                          3    757
модулю 4: 3 (mod 4) ≡ 3 и 757 (mod 4) ≡ 1. Отсюда следует, что (757) ( 3 ) = 1, поэтому,
переворачивая данный символ Лежандра, нужно оставить его знак без изменений:
       3      757           1
     (757) = ( 3 ) = (3) = 1.
                                     11
     2) Символ Лежандра (757).

К данному симолу Лежандра также применим квадратичный закон взаимности.
                                           11   757
Поскольку 757 (mod 4) ≡ 1, то (757) ( 11 ) = 1, следовательно
      11      757           9         32
     (757) = ( 11 ) = (11) = (11) = 1.
                                     17
     3) Символ Лежандра (757).
     К данному симолу Лежандра также применим квадратичный закон взаимности.
                                           17   757
Поскольку 757 (mod 4) ≡ 1, то (757) ( 17 ) = 1, следовательно
      17      757           9         32
     (757) = ( 17 ) = (17) = (11) = 1.
     Теперь можем вычислить значение исходного символа Лежандра:
      561      3       11       17
     (757) = (757) (757) (757) = 1 ∙ 1 ∙ 1 = 1.
     Следовательно, значение 561 является квадратичным вычетом по модулю 757.
