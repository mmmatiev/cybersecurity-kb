Сжатие изображений
• Форматы изображений:
– без сжатия,
– сжатие без потерь,
– сжатие с потерями.
• Алгоритмы сжатия позволяют уменьшить
объем
данных,
необходимых
для
представления
изображения.
Сжатие
основано на устранении из изображения
пространственной избыточности.
• Алгоритм сжатия без потерь обеспечивает
полное
соответствие
восстановленного
изображения исходному.
• Примеры форматов: GIF, PNG, TIFF.
• Алгоритм сжатия c потерями обеспечивает
восстановление изображения из сжатого
образа
с
некоторыми
искажениями,
несущественными
для
человеческого
восприятия.
• Примеры форматов: JPEG, JPEG2000.

Прочие форматы
• Формат PSD – внутренний формат для Adobe Photoshop, позволяет хранить всю
информацию о текущем состоянии работы над изображением: о контурах, каналах,
слоях, векторных надписях, прозрачности, тенях, фильтрах и т.д.
• Формат RAW – в файлах сохраняется информация, которая непосредственно
передается с матрицы цифровой камеры, минуя все возможные процессы
обработки
изображения
(интерполяцию,
повышение
резкости,
урезание
цветности).
• Формат ICO – формат для хранения значков операционной системы Windows,
например, иконок рабочего стола или папок.
