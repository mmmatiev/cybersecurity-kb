# Slides

Презентация является первоисточником. Она не становится canonical Knowledge автоматически.

## Workflow

Incoming → technical inspection → source-note → semantic topics → Knowledge → provenance

1. Поместить новый PDF или PPTX в Incoming.
2. Сохранить оригинал без изменений.
3. При необходимости подготовить PDF-представление.
4. Выполнить локальную техническую инспекцию.
5. Создать одну source-note по шаблону Slides Source.
6. Разделить материал на смысловые темы, а не отдельные страницы.
7. Найти существующие knowledge-notes и дополнить только действительно новым содержанием.
8. Создавать новую knowledge-note только при достаточной содержательности темы.
9. Добавить provenance с диапазонами страниц или слайдов.
10. После успешной интеграции убрать файл из Incoming.

## Storage

- Incoming — необработанные PDF и PPTX.
- Original — исходные PPTX и другие оригиналы, которые нельзя изменять.
- PDF — PDF-представления; исходный PDF хранится здесь без бессмысленного дубликата.
- Processed — только технические результаты инспекции, не knowledge-notes.

## Processing status

Свойство processing_status:

- unprocessed — источник ещё не обработан;
- processing — обработка выполняется;
- processed — интеграция завершена;
- review — интеграция выполнена, но требует ручной проверки.

Именование: Author - Topic - Event Year или Course - Lecture 03 - Topic. Существующие файлы не переименовываются без необходимости.
