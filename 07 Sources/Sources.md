# Sources

Индекс сохранённых источников: презентаций, статей, публикаций, книг, видео, курсов и документации.

Source-note хранит происхождение и краткий разбор материала. Собственное структурированное понимание темы относится в Knowledge.

Поток работы: источник → Sources → осмысление → Knowledge.
