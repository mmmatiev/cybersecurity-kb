# Тематическая навигация

19 пронумерованных страниц тем связывают 110 содержательных карточек двух курсов.
Один общий Canvas показывает две самостоятельные учебные последовательности:
криптографию и стеганографию с техническими основами изображений.
Содержание, расположение и источники карточек сборщик не меняет; он поддерживает только `topic` и `study_order`.

## Проверка и сборка

Из корня Vault:

```sh
python3 -B scripts/knowledge/build_thematic_clusters.py
python3 -B scripts/knowledge/build_thematic_clusters.py --write
python3 -B scripts/knowledge/audit_thematic_clusters.py
python3 -B -m unittest discover -s scripts/knowledge -p 'test_thematic_clusters.py' -v
```

Содержательная редактура карточек дополнительно проверяется так:

```sh
python3 -B scripts/knowledge/audit_editorial_quality.py
python3 -B -m unittest discover -s scripts/knowledge -p 'test*examples.py'
```

Первый скрипт проверяет редакторский контракт 110 карточек, но намеренно не
выдаёт структурную проверку за доказательство математической правильности.
Независимые численные расчёты находятся во втором наборе тестов.

Без `--write` сборщик только проверяет актуальность; код возврата 1 означает
необходимость сборки или конфликт. `--vault-root DIR` позволяет работать с
отдельной тестовой копией. Повторная сборка не меняет файлы и их время записи.

## Изменение маршрутов

- Состав, подгруппы и порядок чтения задаются в `thematic_clusters.py`.
- У каждой карточки одна основная тема. Дополнительные связи не меняют
  основного членства и не создают копий карточек.
- Страницы тем, Base и Canvas принадлежат сборщику. Их hashes и основное
  членство хранятся в `thematic-clusters-manifest.json`.
- В шести родительских MOC сборщик владеет только блоком между маркерами
  `thematic-clusters:start` и `thematic-clusters:end`. Текст вне блока сохраняется.
- Если внутри блока, страницы темы, Base или Canvas есть ручные правки, сборщик
  остановится до записи файлов. Сначала перенесите желаемые правки в данные
  генератора и согласуйте сохранение ручной версии; флага принудительного
  перезаписывания намеренно нет. Не удаляйте manifest для обхода проверки.
- Первая миграция существующих MOC допускается только при совпадении
  контрольных сумм исходных навигационных разделов.
- Генератор второго курса использует ту же навигацию и сохраняет дополнения
  вне её блока. Полную перегенерацию курса проверяйте в копии: она по-прежнему
  может перезаписывать содержательные карточки с маркером генератора.

## Canvas и Obsidian

Canvas использует встроенные файловые узлы, группы и стрелки по
[JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/). Узлы показывают раздел
«Обзор» тематической страницы; открытие страницы даёт полный список карточек.
Стрелки — выбранные учебные зависимости, а не полный граф связей.
Автоматическая проверка контролирует ссылки, размеры и отсутствие наложений.
Читаемость и переходы дополнительно проверяются в Obsidian.

Обратные ссылки из карточек ведут к их тематическим страницам. Обычный Graph
использует Markdown-ссылки; его расположение не фиксируется координатами Canvas.
Дополнительные плагины и изменения `.obsidian` для этой структуры не нужны.
